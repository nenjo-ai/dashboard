# REST Endpoints

All REST endpoints are served under `/api/v1/` and require [Clerk JWT authentication](/docs/api#clerk-jwt-frontend--browser) unless noted otherwise. Request and response bodies use JSON.

## Authentication

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET/POST | `/api/v1/auth/verify` | None | Verify a Clerk session token |
| GET | `/api/v1/auth/me` | Clerk | Get current authenticated user |
