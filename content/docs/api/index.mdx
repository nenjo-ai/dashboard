## Quick overview

Nenjo provides multiple programmatic access paths:

1. **API Keys** — Long-lived tokens for server-to-server access
2. **Platform Scopes** — Fine-grained permissions controlling what resources an API key can access
3. **REST Endpoints** — Full programmatic CRUD operations on Nenjo resources
4. **MCP Server** — Integration with the Model Context Protocol for external tools

<Callout>
  API keys and scopes work together. An API key's permissions are determined by its assigned platform scopes.
</Callout>
