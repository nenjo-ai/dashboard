**Nenji** is your AI assistant in the Nenjo platform. Chat with Nenji to build agents, design routines, create councils, manage projects, and get answers about platform behavior.

## Opening the chat

1. Navigate to **Chat** in the dashboard
2. Type your message or request
3. Press **Enter** to send

Nenji responds in real time, streaming tokens as it generates.

## Basic interactions

Ask Nenji to help with common tasks:

| Request | Example |
|--------|---------|
| Explain a concept | "How do agents use memory?" |
| Build a resource | "Create an agent that summarizes documents" |
| Design a workflow | "Design a routine that checks code on PRs" |
| Review configuration | "Review my API key scopes" |
| Diagnose issues | "Why is my routine failing?" |

## Creator Mode

Creator Mode is a guided interaction mode for building Nenjo resources. When you enable it, Nenji walks you through configuration step-by-step rather than generating a complete manifest upfront.

**Enable Creator Mode:**

1. In the chat input, type `/creator` or click the **Creator** toggle
2. Describe what you want to build
3. Nenji prompts you through each field

Example conversation:

```
You: /creator create an agent
Nenji: Sure! Let's create an agent. What's the agent's name?
You: Document Summarizer
Nenji: What role should the agent play? (e.g., "Summarizes documents concisely")
You: Summarizes documents into bullet points
Nenji: ...
```

<Callout>
  Creator Mode is ideal if you're new to Nenjo or want to explore platform fields interactively. For bulk operations or templates, use the SDK or direct manifest editing.
</Callout>

## @ mentions

Use **@ mentions** to invoke specific agents, routines, or resources inline. This lets you delegate work or pull in specific expertise during a chat.

**Syntax:**

```
@agent:agent-name message
@routine:routine-name input
@project:project-name query
@knowledge:document-id query
```

**Examples:**

```
@agent:code-reviewer Review this PR: https://github.com/...
@routine:daily-standup Trigger today's standup
@project:backend Find all open tasks
@knowledge:security-policy What are the password requirements?
```

### Common @ mentions

| Mention | Purpose |
|--------|---------|
| `@agent:name` | Invoke a specific agent to handle the request |
| `@routine:name` | Trigger a routine execution |
| `@project:name` | Query project resources or tasks |
| `@knowledge:doc-id` | Reference a knowledge document |
| `@council:name` | Invoke a multi-agent council |

## Chat contexts

Each chat session maintains context:

- **Current project** — Resources from the active project are available
- **Recent messages** — Nenji remembers the last 20 messages in the session
- **Retrieval evidence** — Relevant knowledge documents are automatically retrieved

Clear the session to start fresh:

```
/clear
```

## Best practices

1. **Be specific** — "Create an agent that summarizes PDF documents using Claude" works better than "Make an agent"
2. **Use Creator Mode** for step-by-step builds
3. **Use @ mentions** to delegate to specific agents or invoke routines
4. **Reference knowledge documents** explicitly when you need specific context

<Callout type="info">
  Nenji draws on your organization knowledge, retrieval evidence, and platform documentation to answer. For SDK-specific questions, specify "SDK" or "manifest" to get code-level guidance.
</Callout>
