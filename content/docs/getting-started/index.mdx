Nenjo is an AI agent orchestration platform. This section walks you through onboarding and your first interactions with **Nenji**, your AI assistant.

## In this section

| Page | What you'll learn |
|------|------------------|
| [Onboarding](/docs/getting-started/onboarding) | Set up your organization, secure your workspace, create API keys, select models, and connect workers |
| [Chat with Nenji](/docs/getting-started/chat) | Interact with Nenji, use Creator Mode, and leverage @ mentions |

## Quick overview

Nenjo provides two primary interaction paths:

1. **Onboarding** — Initial setup to configure your organization, security, and execution environment
2. **Chat** — Ongoing interaction with Nenji to build agents, design routines, create councils, and manage projects

<Callout>
  New to Nenjo? Start with [Onboarding](/docs/getting-started/onboarding) to set up your workspace before using Chat.
</Callout>
