Nenjo protects your organization's data through **zero-trust end-to-end encryption**, device approval controls, and secure key management. This page covers how to configure security settings for your organization.

## End-to-End Encryption

All organization data is encrypted end-to-end using encryption keys that only your organization members can decrypt. This means:

- **Key ownership** — Your organization owns its encryption keys; Nenjo servers never see plaintext data
- **Key distribution** — Members receive keys through secure channels when they join the organization
- **Data isolation** — Each organization has distinct encryption keys that isolate data from other organizations

<Callout>
  End-to-end encryption is enabled by default for all organizations. You cannot disable it — this is a core security principle.
</Callout>

### How Encryption Works

1. When an organization is created, Nenjo generates a unique encryption key pair
2. The private key is distributed to organization members through their devices
3. All data (documents, agent prompts, memory, routines) is encrypted before leaving the device
4. Only members with approved devices can decrypt organization data

## Device Approval

Device approval ensures that only trusted devices can access organization data. Before a device can decrypt organization content:

1. **New device registration** — A user attempts to access from a new device
2. **Approval request** — An existing organization member must approve the device
3. **Key distribution** — Once approved, the encryption key is shared with the device
4. **Access granted** — The device can now decrypt organization data

### Configuring Device Approval

Organization owners and admins can configure device approval settings:

- **Require approval** — All new devices require member approval (default: enabled)
- **Auto-approve domains** — Automatically approve devices from configured email domains
- **Session duration** — How long a device can access before re-authentication

## Key Rotation

Key rotation periodically refreshes encryption keys to limit the impact of potential key compromise.

### Manual Key Rotation

Organization owners can trigger manual key rotation:

1. Go to **Organization Settings** → **Security** → **Key Rotation**
2. Click **Rotate Keys**
3. Confirm the rotation — all members will receive new encryption keys on their next login

<Callout>
  During key rotation, organization members must reconnect their devices. Plan key rotation during low-activity periods to minimize disruption.
</Callout>

### Automatic Key Rotation

Organizations can enable automatic key rotation:

- **Annual rotation** — Keys rotate every 12 months
- **Semi-annual rotation** — Keys rotate every 6 months (recommended for sensitive data)
- **Quarterly rotation** — Keys rotate every 3 months

## Inviting Members

Organization members invite new collaborators through secure invite links:

1. Go to **Organization Settings** → **Members**
2. Click **Invite Member**
3. Enter the invitee's email address and select a role
4. The invitee receives a secure link to join the organization

### Invite Security

- **One-time links** — Invite links expire after 7 days or upon use
- **Email verification** — Invitees must verify their email before joining
- **Role assignment** — Invitees receive the role specified by the inviter
- **Revocation** — Organization owners can revoke pending invites
