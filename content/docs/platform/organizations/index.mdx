## What is an Organization

An organization is a shared workspace where team members collaborate on Nenjo projects, agents, and resources. Each organization has:

- **Members** — Users who belong to the organization with defined roles
- **Projects** — Shared project containers for team work
- **Agents** — Collaborative agent configurations accessible to members
- **Security** — Encryption, device approval, and access controls

<Callout>
  Every Nenjo user belongs to at least one organization — your personal workspace. As you invite team members, your organization grows to include collaborators.
</Callout>

## Key concepts

### Member Roles

Organization members have roles that define their permissions:

- **Owner** — Full administrative access, can manage billing and security
- **Admin** — Manage members, projects, and agents
- **Member** — Access shared projects and collaborate on work

### Shared Resources

Team members share access to:

- **Projects** — Work containers visible to organization members
- **Agents** — Agent configurations with shared prompt configuration and memory
- **Knowledge** — Documents and context blocks for team knowledge base
- **Routines** — Workflow definitions for team automation
