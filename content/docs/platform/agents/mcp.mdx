MCP (Model Context Protocol) integration allows agents to connect to external tools and services. MCP servers expose capabilities that agents can use during execution, extending their ability to interact with real-world systems.## What is MCP

MCP (Model Context Protocol) is a standardized protocol for connecting AI models to external tools and services. It provides a consistent interface for:- **File system access** — Reading and writing files
- **Git operations** — Repository management
- **Web requests** — HTTP calls to external APIs
- **Database queries** — Structured data access
- **Custom integrations** — Any external service## MCP Server Configuration
MCP servers are configured as resources that can be assigned to agents, abilities, and domains.### Server Types
| Type | Transport | Use Case |
|------|-----------|----------|
| **stdio** | Local process | Local tools, development utilities |
| **HTTP** | REST API | Remote services, web APIs |
| **SSE** | Server-Sent Events | Real-time data streams |
### Example MCP Server Configuration
```yaml
mcp_servers:
  - name: filesystem
    type: stdio
    command: npx
    args: ["-y", "@modelcontextprotocol/server-filesystem", "/workspace"]
    description: File system access for the project workspace
  
  - name: github
    type: http
    url: https://api.github.com
    description: GitHub API integration
    
  - name: database
    type: stdio
    command: ./mcp-server
    args: ["--db", "postgres://localhost/app"]
    description: Database query interface
```## Assigning MCP Servers to Agents
MCP servers are assigned to agents through the agent's capability surface:```yaml
agent:  name: implementer  model: claude-sonnet
  mcp_server_ids:    - filesystem
    - github
    - database```## MCP in Abilities and Domains
MCP servers can also be assigned to abilities and domains, providing scoped access to external tools:```yaml
ability:  name: code_review  tool_name: code_review  mcp_server_ids:    - filesystem    - github  # Only these servers available during ability execution
domain:  name: production  command: /prod-mode  mcp_server_ids:    - kubernetes    - monitoring
  # Expanded MCP access during domain session```## Best Practices
1. **Assign minimum required servers** — Only what the agent actually needs
2. **Use scoped access** — Assign MCP servers to abilities/domains, not globally
3. **Secure sensitive servers** — Use authentication and access controls
4. **Monitor usage** — Track which tools are being used
5. **Document server capabilities** — Help agents understand available tools## Common MCP Integrations
- **Filesystem** — Local file operations
